# 退货管理模块 (spd-refund)

## 模块定位

退货申请、退货审批、退货出库、退款处理

## 功能说明

| 功能 | 说明 |
|------|------|
| 退货申请 | 医院发起/供应商发起退货、退货类型选择、退货原因填写 |
| 退货审核 | 退货原因审核、退货数量确认、审核意见、驳回重提 |
| 退货出库 | 退货商品出库、库存回退、退货单生成、出库记录 |
| 退款处理 | 退货关联退款、退款金额核算、退款记录、退款状态跟踪 |
| 退货跟踪 | 退货物流、退货状态跟踪、退货历史查询 |

## 核心API

```java
// 退货单分页查询
GET /api/refund/page?pageNum=1&pageSize=10&hospitalId=xxx&status=1

// 创建退货单
POST /api/refund
Body: {refundNo, orderId, acceptanceId, hospitalId, refundType, remark, items: [{productId, orderItemId, batchNo, refundQty, unitPrice, refundReason}]}

// 退货审核
PUT /api/refund/{id}/audit
Body: {auditStatus, auditRemark}

// 退货出库
PUT /api/refund/{id}/outbound

// 退货完成
PUT /api/refund/{id}/complete
Body: {completeRemark, logisticsNo}

// 取消退货
PUT /api/refund/{id}/cancel
Body: {cancelReason}

// 更新退货单
PUT /api/refund/{id}
Body: {refundType, remark, items: [{productId, orderItemId, batchNo, refundQty, unitPrice, refundReason}]}

// 删除退货单
DELETE /api/refund/{id}

// 获取退货明细
GET /api/refund/{id}/items
```

## 退货状态流转

```
待审核 ──审核通过──→ 已审核 ──出库──→ 退货中 ──完成──→ 已完成
   │                        │
   └───审核驳回──→ 驳回    └──取消──→ 已关闭
```

## 页面按钮 - API - 状态 - 异常码对照表

| 页面按钮 | 对应 API | 允许状态 | 成功后状态 | 主要异常码 |
|----------|----------|----------|------------|------------|
| 新增 | `POST /api/refund` | 验收完成、库存可退 | 待审核 | `REFUND_QTY_EXCEED_AVAILABLE`、`REFUND_SOURCE_INVALID` |
| 编辑 | `PUT /api/refund/{id}` | 待审核、驳回 | 待审核 | `REFUND_LOCKED`、`REFUND_ITEM_INVALID` |
| 删除 | `DELETE /api/refund/{id}` | 待审核、驳回 | 已关闭 | `REFUND_AUDITED`、`REFUND_NOT_FOUND` |
| 审核 | `PUT /api/refund/{id}/audit` | 待审核 | 已审核或驳回 | `AUDIT_STATUS_INVALID`、`REFUND_QTY_CHANGED` |
| 出库 | `PUT /api/refund/{id}/outbound` | 已审核 | 退货中 | `INVENTORY_NOT_ENOUGH`、`OUTBOUND_WRITE_FAILED` |
| 查看明细 | `GET /api/refund/{id}/items` | 全部 | 原状态不变 | `REFUND_NOT_FOUND` |
| 导出 | `GET /api/refund/page` | 全部 | 原状态不变 | `EXPORT_TOO_MANY_ROWS` |

## 状态转移条件与失败回滚

| 转移 | 可转移条件 | 禁止转移 | 失败回滚 |
|------|------------|----------|----------|
| 待审核 → 已审核 | 退货来源有效、数量不超过可退数量、审核意见完整 | 来源单据已关闭、库存已被占用 | 保持待审核，记录审核失败原因 |
| 待审核 → 驳回 | 审核意见填写驳回原因 | 驳回原因为空 | 保持待审核 |
| 驳回 → 待审核 | 申请人修改退货原因或数量后重新提交 | 原验收单已冲销或库存不可退 | 保持驳回状态 |
| 已审核 → 退货中 | 库存批次可用，出库流水写入成功 | 库存不足、批号不存在 | 回滚库存扣减和出库流水 |
| 退货中 → 已完成 | 退货物流或医院确认完成，退款金额核算完成 | 退款金额未确认、物流未签收 | 保持退货中 |
| 已审核 → 已关闭 | 未出库且取消原因完整 | 已出库或已完成 | 保持已审核 |

#### 弹窗布局
```
┌─────────────────────────────────────────────────────────────────┐
│  编辑退货单 - TH20240001                     [×]              │
├─────────────────────────────────────────────────────────────────┤
│  基本信息: 退货单号* 关联订单* 关联验收* 医院* 退货类型* 退货原因* │
│  退货明细: ┌──────────────────────────────────────────┐              │
│           │☑ 商品编码 商品名称 规格 批号 退货数量 单价 退货原因  │
│           │☑ YLQX001 医用口罩 10只 批号A 10 5.00 质量问题  │
│           └──────────────────────────────────────────┘              │
│  备注: [多行文本框]                                              │
│                              [取消]  [保存]  [提交审核]           │
└─────────────────────────────────────────────────────────────────┘
```

#### 表单字段说明

| 区域 | 字段 | 必填 | 说明 |
|------|------|------|------|
| 基本信息 | 退货单号 | 是 | 系统自动生成或按规则录入，不允许重复 |
| 基本信息 | 关联订单 | 是 | 只能选择存在可退商品的订单 |
| 基本信息 | 关联验收 | 是 | 用于定位批号、效期、UDI 和可退数量 |
| 基本信息 | 医院 | 是 | 根据关联订单或验收单带出 |
| 基本信息 | 退货类型 | 是 | 质量问题、数量差异、错发、召回、其他 |
| 基本信息 | 退货原因 | 是 | 提交审核时必须填写 |
| 退货明细 | 商品、批号 | 是 | 从验收明细或库存批次中选择 |
| 退货明细 | 退货数量 | 是 | 必须大于 0，且不得超过可退数量 |
| 退货明细 | 单价 | 是 | 默认取订单或结算单价 |
| 备注 | 备注 | 否 | 记录补充说明 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|----------|
| 取消 | 关闭弹窗，不保存修改 |
| 保存 | 保存退货草稿或待审核单据 |
| 提交审核 | 校验退货来源、数量和库存后提交审核 |

#### 提交校验规则

- 关联订单、关联验收、退货类型、退货原因和退货明细不能为空。
- 退货数量不得超过当前批次可退数量。
- 已结算或已开票的商品退货需标记后续冲红或差异结算处理。
- 提交审核后，除驳回重提外不得直接修改退货明细。
