# 采购计划管理模块 (spd-plan)

## 模块定位

采购需求收集、计划编制、审批流转、计划转订单

## 功能说明

| 功能    | 说明                    |
| ----- | --------------------- |
| 计划创建  | 医院发起采购需求、供应商响应、计划模板导入 |
| 计划明细  | 商品、数量、期望交期、备注、附件上传    |
| 计划审批  | 多级审批流程、审批意见、审批历史、驳回重提 |
| 计划转订单 | 审批通过后一键生成采购订单、支持分批转单  |
| 计划跟踪  | 计划执行状态、已转订单数量、完成率统计   |

## 核心API

```java
// 采购计划分页查询
GET /api/plan/page?pageNum=1&pageSize=10&hospitalId=xxx&status=1

// 创建采购计划
POST /api/plan
Body: {planNo, hospitalId, planDate, deliveryDate, remark, items: [{productId, planQty, unitPrice, remark}]}

// 计划提交审批
PUT /api/plan/{id}/submit

// 计划审批
PUT /api/plan/{id}/audit
Body: {auditStatus, auditRemark}

// 计划转订单
POST /api/plan/{id}/convert-order
Body: {itemIds: [1, 2, 3]}

// 获取计划明细
GET /api/plan/{id}/items
```

## 计划状态流转

```
草稿 ──提交──→ 待审批 ──审批通过──→ 已审批 ──转订单──→ 部分转单 ──全部转单──→ 已转单
  │                    │                                      │
  └───删除            └───审批驳回──→ 驳回 ──修改──→ 草稿  └───关闭──→ 已关闭
```

#### 页面功能说明

**查询条件：**

| 查询项  | 查询方式   | 说明              |
| ---- | ------ | --------------- |
| 商品编码 | 模糊查询   | 支持输入关键字模糊匹配商品编码 |

| ------ | -------------------------- |
| 确认     | 确认选中的采购计划                  |
| 计划转配送单 | 选中一条或多条采购计划，跳转到配送单页面，生成配送单 |
| 导出     | 导出当前查询结果为Excel文件           |

| 配送日期  | 是  | 日期选择器       |

**配送商品明细区域：**

| 字段    | 必填 | 说明                        |
| ----- | -- | ------------------------- |
| 商品编码  | 是  | 只读，商品编码                   |
| 商品名称  | 是  | 只读，商品名称                   |
| 规格    | 是  | 只读，商品规格                   |
| 型号    | 是  | 只读，商品型号                   |
| 单位    | 是  | 只读，商品单位                   |
| 单价    | 是  | 只读，商品单价                   |
| 厂家    | 是  | 只读，厂家                     |
| 计划数量  | 是  | 只读，计划配送数量                 |
| 配送数量  | 是  | 可编辑，配送数量                  |
| 生产日期  | 是  | 可编辑，生产日期不能大于当天日期          |
| 失效日期  | 是  | 可编辑，失效日期不能大于当天日期          |
| 批号    | 是  | 可编辑，商品批号                  |
| 未配送数量 | 是  | 自动计算，未配送数量 = 计划数量 - 已配送数量 |
| 备注    | 否  | 备注信息                      |

**备注区域：**

| 字段 | 必填 | 说明           |
| -- | -- | ------------ |
| 备注 | 否  | 多行文本框，输入备注信息 |

#### 编辑功能说明

**部分完成再次编辑：**

- 支持配送单状态为"部分完成"时，可以再次编辑
- 可以修改已配送数量
- 未配送数量自动计算
- 所有商品未配送数量为0时，状态可改为"全部完成"

#### 弹窗操作按钮

| 按钮 | 功能说明                             |
| -- | -------------------------------- |
| 取消 | 关闭弹窗，不保存数据                       |
| 确认 | 保存编辑内容，不提交                       |
| 提交 | 保存编辑内容并提交，提交完成后，配送单部分完成的状态改为全部完成 |

#### 提交校验规则

- 必填字段不能为空
- 已配送数量不能大于计划数量
- 所有商品未配送数量为0时，状态改为"全部完成"
- 存在未配送商品时，状态保持"部分完成"
