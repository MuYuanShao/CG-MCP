# 结算单管理模块 (spd-settlement)

## 模块定位

结算单生成、对账确认、结算审批、差异处理

## 功能说明

| 功能 | 说明 |
|------|------|
| 结算单生成 | 按周期/按订单汇总验收数据生成结算单、支持手动调整 |
| 结算明细 | 关联验收单、商品明细、数量金额汇总、价税分离 |
| 对账确认 | 供应商与医院双向确认、确认意见、确认历史 |
| 结算审批 | 结算单审批流程、多级审批、审批意见 |
| 差异处理 | 对账差异标记、差异原因记录、协商处理、差异调整 |

## 核心API

```java
// 结算单分页查询
GET /api/settlement/page?pageNum=1&pageSize=10&hospitalId=xxx&status=1

// 生成结算单
POST /api/settlement/generate
Body: {hospitalId, settlementStart, settlementEnd}

// 更新结算单
PUT /api/settlement/{id}
Body: {settlementStart, settlementEnd, adjustAmount, differenceRemark, items}

// 删除结算单
DELETE /api/settlement/{id}

// 供应商确认
PUT /api/settlement/{id}/supplier-confirm
Body: {confirmStatus, confirmRemark}

// 医院确认
PUT /api/settlement/{id}/hospital-confirm
Body: {confirmStatus, confirmRemark}

// 结算审批
PUT /api/settlement/{id}/audit
Body: {auditStatus, auditRemark}

// 获取结算明细
GET /api/settlement/{id}/items

// 标记结算差异
PUT /api/settlement/{id}/difference
Body: {differenceType, differenceAmount, differenceReason, handleRemark}
```

## 结算流程

```
生成结算单 → 供应商确认 → 医院确认 → 结算审批 → 差异处理 → 结算完成 → 进入开票环节
```

## 结算状态流转

```
待确认 → 供应商已确认 → 医院已确认 → 待审批 → 已完成 → 待开票
   │           │              │          │
   │           └── 有差异 → 差异处理中 ──┘
   └── 删除 → 已关闭
```

## 页面按钮 - API - 状态 - 异常码对照表

| 页面按钮 | 对应 API | 允许状态 | 成功后状态 | 主要异常码 |
|----------|----------|----------|------------|------------|
| 生成结算单 | `POST /api/settlement/generate` | 验收已完成、未结算 | 待确认 | `NO_SETTLEABLE_ITEMS`、`SETTLEMENT_PERIOD_OVERLAP` |
| 编辑 | `PUT /api/settlement/{id}` | 待确认、差异处理中 | 原状态不变 | `SETTLEMENT_LOCKED`、`AMOUNT_NOT_MATCH` |
| 删除 | `DELETE /api/settlement/{id}` | 待确认 | 已关闭 | `SETTLEMENT_CONFIRMED`、`SETTLEMENT_NOT_FOUND` |
| 供应商确认 | `PUT /api/settlement/{id}/supplier-confirm` | 待确认、差异处理中 | 供应商已确认或差异处理中 | `CONFIRM_AMOUNT_MISMATCH` |
| 医院确认 | `PUT /api/settlement/{id}/hospital-confirm` | 供应商已确认 | 医院已确认或差异处理中 | `HOSPITAL_CONFIRM_REJECTED` |
| 审批 | `PUT /api/settlement/{id}/audit` | 医院已确认、待审批 | 已完成或差异处理中 | `AUDIT_STATUS_INVALID` |
| 查看明细 | `GET /api/settlement/{id}/items` | 全部 | 原状态不变 | `SETTLEMENT_NOT_FOUND` |
| 导出 | `GET /api/settlement/page` | 全部 | 原状态不变 | `EXPORT_TOO_MANY_ROWS` |

## 状态转移条件与失败回滚

| 转移 | 可转移条件 | 禁止转移 | 失败回滚 |
|------|------------|----------|----------|
| 验收完成 → 待确认 | 验收单未结算，金额计算无差异 | 结算周期重叠、存在未完成退货 | 删除生成的结算明细，释放验收单结算标记 |
| 待确认 → 供应商已确认 | 供应商确认金额与系统金额一致 | 金额不一致且未标记差异 | 保持待确认，记录供应商确认意见 |
| 供应商已确认 → 医院已确认 | 医院确认金额与供应商一致 | 医院确认驳回或差异金额为空 | 进入差异处理中或保持供应商已确认 |
| 差异处理中 → 待审批 | 差异原因、调整金额和双方意见完整 | 差异未闭环 | 保持差异处理中 |
| 待审批 → 已完成 | 审批通过，结算金额锁定 | 审批驳回、下游开票已存在异常 | 回滚审批记录和结算完成状态 |
| 已完成 → 待开票 | 发票模块接收结算单成功 | 发票模块不可用或结算单被撤销 | 保持已完成，等待重试 |

### 结算单编辑弹窗

#### 弹窗布局
```
┌─────────────────────────────────────────────────────────────────┐
│  编辑结算单 - JS20240001                     [×]              │
├─────────────────────────────────────────────────────────────────┤
│  基本信息: 结算单号* 医院* 结算开始* 结算结束* 结算金额          │
│  结算明细: ┌──────────────────────────────────────────┐              │
│           │☑ 验收单号 商品编码 商品名称 规格 数量 单价 金额  │
│           │☑ YS20240001 YLQX001 医用口罩 100 5.00 500.00│
│           └──────────────────────────────────────────┘              │
│  差异标记: [多行文本框]                                              │
│                              [取消]  [保存]  [供应商确认]           │
└─────────────────────────────────────────────────────────────────┘
```

#### 表单字段说明

| 区域 | 字段 | 必填 | 说明 |
|------|------|------|------|
| 基本信息 | 结算单号 | 是 | 系统自动生成或按规则录入，不允许重复 |
| 基本信息 | 医院 | 是 | 选择需要结算的合作医院 |
| 基本信息 | 结算开始、结算结束 | 是 | 结算周期不能与已有结算单重叠 |
| 基本信息 | 结算金额 | 是 | 根据验收、退货和调整项自动计算 |
| 结算明细 | 验收单号 | 是 | 只能选择已完成且未结算的验收单 |
| 结算明细 | 商品、数量、单价、金额 | 是 | 从验收明细和订单价格带出 |
| 差异标记 | 差异原因、调整金额 | 条件必填 | 双方确认金额不一致时必填 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|----------|
| 取消 | 关闭弹窗，不保存修改 |
| 保存 | 保存结算单和差异说明 |
| 供应商确认 | 供应商确认结算金额或标记差异 |

#### 提交校验规则

- 医院、结算周期和结算明细不能为空。
- 结算周期不得与同医院已有未关闭结算单重叠。
- 结算金额必须等于明细金额、退货扣减和调整金额的合计。
- 存在差异时，必须填写差异原因、调整金额和处理意见。
- 已完成或已开票的结算单不得编辑或删除。
