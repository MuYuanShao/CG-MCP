# 用户管理模块 (spd-user)

## 模块定位

租户用户生命周期管理、组织架构维护

## 功能说明

| 功能 | 说明 |
|------|------|
| 用户注册/登录 | 供应商用户自助注册、手机号/邮箱登录、第三方登录（预留） |
| 用户信息管理 | 用户CRUD、状态管理（启用/禁用/锁定）、密码重置、头像管理 |
| 组织架构 | 供应商企业信息、部门树管理、部门-用户关联 |
| 用户关联 | 用户-供应商绑定、用户-角色分配、用户-数据范围配置 |

## 核心API

```java
// 用户分页查询
GET /api/user/page?pageNum=1&pageSize=10&keyword=xxx

// 创建用户
POST /api/user
Body: {username, realName, phone, email, deptId, roleIds}

// 分配角色
PUT /api/user/{id}/roles
Body: {roleIds: [1, 2, 3]}

// 重置密码
PUT /api/user/{id}/password
Body: {newPassword}
```

## 业务流程

```
用户注册 → 手机号验证 → 绑定租户 → 分配默认角色 → 账号激活
```

#### 页面功能说明

**查询条件：**
| 查询项 | 查询方式 | 说明 |
|--------|---------|------|
| 用户名 | 模糊查询 | 支持输入关键字模糊匹配用户名 |
| 真实姓名 | 模糊查询 | 支持输入关键字模糊匹配真实姓名 |
| 手机号 | 模糊查询 | 支持输入关键字模糊匹配手机号 |
| 部门 | 下拉选择 | 从部门表获取下拉选项 |
| 状态 | 下拉选择 | 全部、启用、禁用、锁定 |

**数据展示：**
- 页面默认展示当前登录账号可见的用户信息
- 每页默认展示25条数据
- 支持勾选多条数据（用于批量操作）
- 列表字段：用户名、真实姓名、手机号、邮箱、部门、角色、状态

**状态说明：**
- 启用：用户可以正常登录
- 禁用：用户无法登录
- 锁定：用户账号被锁定，需解锁

**页面按钮：**
| 按钮 | 功能说明 |
|------|---------|
| 新增 | 打开新增用户弹窗 |
| 编辑 | 选中一条用户，打开编辑用户弹窗 |
| 删除 | 选中一条或多条用户，删除用户 |
| 重置密码 | 选中一条用户，重置用户密码 |
| 分配角色 | 选中一条用户，打开角色分配弹窗 |
| 导入 | 打开用户导入弹窗，支持Excel批量导入 |
| 导出 | 导出当前查询结果为Excel文件 |

#### 表单字段说明

**基本信息区域：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 用户名 | 是 | 用户登录名，唯一 |
| 真实姓名 | 是 | 用户真实姓名 |
| 手机号 | 是 | 手机号码，用于验证和通知 |
| 邮箱 | 否 | 邮箱地址 |
| 密码 | 是 | 用户密码，编辑时不可见 |

**组织信息区域：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 部门 | 是 | 下拉选择，从部门表获取 |
| 角色 | 是 | 下拉选择，从角色表获取 |

**备注区域：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 备注 | 否 | 多行文本框，输入备注信息 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|---------|
| 取消 | 关闭弹窗，不保存数据 |
| 确认保存 | 校验表单数据，保存用户信息 |

#### 保存校验规则

- 必填字段不能为空
- 用户名必须唯一
- 手机号格式校验
- 邮箱格式校验（如有）
- 密码强度校验（新增时）
