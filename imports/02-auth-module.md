# 权限管理模块 (spd-auth)

## 模块定位

RBAC权限体系、认证授权、安全控制

## 功能说明

| 功能 | 说明 |
|------|------|
| 角色管理 | 角色CRUD、角色-权限关联、角色-数据范围配置 |
| 菜单权限 | 菜单树管理、按钮级权限控制、动态路由生成 |
| 数据权限 | 数据范围策略（全部/本供应商/本部门/本人）、SQL自动注入 |
| 租户隔离 | 基于tenant_id的行级数据隔离，SQL拦截器自动处理 |
| 认证授权 | JWT Token生成与校验、登录态管理、权限拦截器 |

## 数据权限策略设计

```
数据范围枚举：
- DATA_SCOPE_ALL        → 查看所有供应商数据（平台管理员）
- DATA_SCOPE_TENANT     → 仅查看本供应商数据（供应商用户）
- DATA_SCOPE_DEPT       → 仅查看本部门数据
- DATA_SCOPE_SELF       → 仅查看本人数据

实现机制：
- MyBatis-Plus DataPermissionInterceptor
- 自定义SQL解析器，自动注入WHERE条件
- 支持自定义数据权限规则扩展
```

## 核心API

```java
// 登录
POST /api/auth/login
Body: {username, password, tenantId}
Response: {token, userInfo, permissions}

// 获取角色列表
GET /api/auth/roles

// 创建角色
POST /api/auth/roles
Body: {roleName, roleCode, dataScope, menuIds}

// 获取当前用户权限
GET /api/auth/permissions
```

#### 页面功能说明

**查询条件：**
| 查询项 | 查询方式 | 说明 |
|--------|---------|------|
| 角色名称 | 模糊查询 | 支持输入关键字模糊匹配角色名称 |
| 数据范围 | 下拉选择 | 全部、全部数据、本供应商、本部门、本人 |
| 状态 | 下拉选择 | 全部、启用、禁用 |

**数据展示：**
- 页面默认展示当前登录账号可见的角色信息
- 每页默认展示25条数据
- 支持勾选多条数据（用于批量操作）
- 列表字段：角色名称、角色编码、数据范围、状态、描述

**数据范围说明：**
- 全部数据：查看所有数据（平台管理员）
- 本供应商：仅查看本供应商数据
- 本部门：仅查看本部门数据
- 本人：仅查看本人数据

**页面按钮：**
| 按钮 | 功能说明 |
|------|---------|
| 新增 | 打开新增角色弹窗 |
| 编辑 | 选中一条角色，打开编辑角色弹窗 |
| 删除 | 选中一条或多条角色，删除角色 |
| 分配菜单 | 选中一条角色，打开菜单分配弹窗 |
| 复制 | 选中一条角色，复制角色信息 |
| 导出 | 导出当前查询结果为Excel文件 |

#### 表单字段说明

**基本信息区域：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 角色名称 | 是 | 角色显示名称 |
| 角色编码 | 是 | 角色唯一编码 |
| 数据范围 | 是 | 单选：全部数据、本供应商、本部门、本人 |

**菜单权限区域：**
- 菜单树展示
- 支持多选菜单
- 支持全选/取消全选
- 支持展开/收起菜单节点

**描述区域：**
| 字段 | 必填 | 说明 |
|------|------|------|
| 描述 | 否 | 多行文本框，输入角色描述 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|---------|
| 取消 | 关闭弹窗，不保存数据 |
| 确认保存 | 校验表单数据，保存角色信息 |

#### 保存校验规则

- 必填字段不能为空
- 角色名称必须唯一
- 角色编码必须唯一
