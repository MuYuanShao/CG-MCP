# 院内验收单管理模块 (spd-acceptance)

## 模块定位

到货验收、质量检验、UDI追溯、差异处理

## 功能说明

| 功能 | 说明 |
|------|------|
| 验收单创建 | 关联采购订单、自动带入订单明细、验收日期录入 |
| 验收明细 | 逐商品验收、批号、效期、UDI扫码录入、合格/不合格判定 |
| 质量检验 | 检验项目记录、检验结果录入、不合格原因记录、检验报告上传 |
| 验收差异 | 实收与应收差异处理、差异原因记录、差异通知供应商 |
| 验收确认 | 验收通过后自动更新库存、触发结算、验收单归档 |
| 验收追溯 | 验收记录查询、验收历史追溯、UDI全链路追溯 |

## 核心API

```java
// 验收单分页查询
GET /api/acceptance/page?pageNum=1&pageSize=10&orderId=xxx&status=1

// 创建验收单
POST /api/acceptance
Body: {acceptanceNo, orderId, hospitalId, acceptanceDate, remark}

// 获取验收明细
GET /api/acceptance/{id}/items

// 验收明细录入
PUT /api/acceptance/{id}/items
Body: [{orderItemId, batchNo, productionDate, expireDate, udiCode, acceptQty, qualifiedQty, unqualifiedQty, unqualifiedReason}]

// 验收确认
PUT /api/acceptance/{id}/confirm

// 差异处理
PUT /api/acceptance/{id}/difference
Body: {differenceType, differenceReason, supplierNotifyFlag, handleRemark}

// 驳回验收单
PUT /api/acceptance/{id}/reject
Body: {rejectReason}

// 重开验收单
PUT /api/acceptance/{id}/reopen
Body: {reopenReason}

// 删除验收单
DELETE /api/acceptance/{id}
```

## 验收流程

```
到货通知 → 创建验收单 → 商品清点 → UDI扫码 → 质量检验 → 验收判定 → 差异处理 → 验收确认 → 库存更新
```

## 验收状态流转

```
待验收 → 验收中 → 部分验收 → 差异处理中 → 待确认 → 已完成
   │        │           │              │
   │        └── 驳回 → 已驳回           └── 重开 → 验收中
   └── 删除 → 已关闭
```

## 页面按钮 - API - 状态 - 异常码对照表

| 页面按钮 | 对应 API | 允许状态 | 成功后状态 | 主要异常码 |
|----------|----------|----------|------------|------------|
| 新增 | `POST /api/acceptance` | 订单已到货、未验收 | 待验收 | `ORDER_NOT_ARRIVED`、`ACCEPTANCE_EXISTS` |
| 编辑 | `PUT /api/acceptance/{id}/items` | 待验收、验收中、部分验收、差异处理中 | 验收中或待确认 | `ACCEPTANCE_LOCKED`、`ITEM_QTY_INVALID` |
| 删除 | `DELETE /api/acceptance/{id}` | 待验收、已驳回 | 已关闭 | `ACCEPTANCE_CONFIRMED`、`ACCEPTANCE_NOT_FOUND` |
| 验收确认 | `PUT /api/acceptance/{id}/confirm` | 待确认、差异处理中 | 已完成 | `INVENTORY_WRITE_FAILED`、`DIFFERENCE_UNRESOLVED` |
| 查看明细 | `GET /api/acceptance/{id}/items` | 全部 | 原状态不变 | `ACCEPTANCE_NOT_FOUND` |
| 打印 | `GET /api/acceptance/{id}/items` | 待确认、已完成 | 原状态不变 | `PRINT_TEMPLATE_NOT_FOUND` |
| 导出 | `GET /api/acceptance/page` | 全部 | 原状态不变 | `EXPORT_TOO_MANY_ROWS` |

## 状态转移条件与失败回滚

| 转移 | 可转移条件 | 禁止转移 | 失败回滚 |
|------|------------|----------|----------|
| 待验收 → 验收中 | 订单已到货，验收单未被其他人锁定 | 订单未发货、已取消、已验收 | 释放验收锁，保持待验收 |
| 验收中 → 部分验收 | 至少一条明细存在实收数量或不合格数量 | 所有明细数量均为空 | 回滚本次明细保存 |
| 部分验收 → 差异处理中 | 实收数量、合格数量或不合格数量与应收存在差异 | 差异原因为空 | 保留明细，阻止确认 |
| 差异处理中 → 待确认 | 差异原因、处理意见和供应商通知结果完整 | 差异未处理或通知失败 | 保持差异处理中，记录通知失败 |
| 待确认 → 已完成 | 明细校验通过，库存入库成功，触发结算准备成功 | 库存回写失败、批号/UDI 无效 | 回滚库存流水、批次库存和验收状态 |
| 已完成 → 验收中 | 管理员重开且下游结算未生成 | 已生成结算单或发票 | 拒绝重开，保留已完成状态 |

### 验收单编辑弹窗

#### 弹窗布局
```
┌─────────────────────────────────────────────────────────────────┐
│  编辑验收单 - YS20240001                     [×]              │
├─────────────────────────────────────────────────────────────────┤
│  基本信息: 验收单号* 采购订单* 医院* 验收日期*                   │
│  验收明细: ┌──────────────────────────────────────────┐              │
│           │☑ 商品编码 商品名称 规格 应收数 实收数 合格数 不合格数 UDI │
│           │☑ YLQX001 医用口罩 10只 100 100 100 0 UDI001  │
│           └──────────────────────────────────────────┘              │
│  备注: [多行文本框]                                              │
│                              [取消]  [保存]  [确认验收]           │
└─────────────────────────────────────────────────────────────────┘
```

#### 表单字段说明

| 区域 | 字段 | 必填 | 说明 |
|------|------|------|------|
| 基本信息 | 验收单号 | 是 | 系统自动生成或按规则录入，不允许重复 |
| 基本信息 | 采购订单 | 是 | 只能选择已到货且未完成验收的订单 |
| 基本信息 | 医院 | 是 | 根据采购订单自动带出 |
| 基本信息 | 验收日期 | 是 | 不得早于到货日期 |
| 验收明细 | 应收数 | 是 | 从订单或发货明细带出，不可大于发货数量 |
| 验收明细 | 实收数 | 是 | 不得小于 0，不得大于应收数 |
| 验收明细 | 合格数 | 是 | 合格数 + 不合格数应等于实收数 |
| 验收明细 | 不合格数 | 是 | 大于 0 时必须填写不合格原因 |
| 验收明细 | 批号、效期、UDI | 条件必填 | 医疗器械类商品必须记录 UDI 或豁免原因 |
| 备注 | 备注 | 否 | 记录验收说明或差异说明 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|----------|
| 取消 | 关闭弹窗，不保存修改 |
| 保存 | 保存验收基础信息和明细，状态保持待验收或验收中 |
| 确认验收 | 执行数量、质量、UDI 和库存回写校验，通过后完成验收 |

#### 提交校验规则

- 验收明细不能为空，且每条明细必须填写实收数、合格数和不合格数。
- 合格数与不合格数之和必须等于实收数。
- 存在数量差异或不合格数量时，必须先完成差异处理。
- 确认验收前需要校验批号、效期、UDI、证照效期和库存入库权限。
- 库存回写失败时，验收单不得进入已完成状态。
