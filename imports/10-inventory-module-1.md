# 库存管理模块 (spd-inventory)

## 模块定位

库存台账、出入库管理、效期预警、库存盘点

## 功能说明

| 功能 | 说明 |
|------|------|
| 库存台账 | 实时库存查询、批次管理、库位管理、库存明细查询 |
| 入库管理 | 采购入库、退货入库、入库单生成、入库确认 |
| 出库管理 | 销售出库、退货出库、出库单生成、出库确认、锁定库存 |
| 效期管理 | 效期预警（近效期/过期）、先进先出策略、效期拦截 |
| 库存盘点 | 盘点计划、盘点单生成、盘点录入、盘盈盘亏处理、盘点差异审核 |
| 库存预警 | 上下限预警、安全库存提醒、预警消息推送 |
| 批次追溯 | 批号+效期+UDI全链路追溯、出入库流水查询 |

## 核心API

```java
// 库存分页查询
GET /api/inventory/page?pageNum=1&pageSize=10&productId=xxx&warehouseId=xxx

// 获取库存明细
GET /api/inventory/{productId}/detail

// 库存批次查询
GET /api/inventory/{productId}/batches

// 库存流水查询
GET /api/inventory/{inventoryId}/logs

// 获取效期预警列表
GET /api/inventory/expire-alerts?alertLevel=1&isHandled=0

// 处理效期预警
PUT /api/inventory/expire-alerts/{id}/handle
Body: {handleRemark}
```

## 效期预警策略

```
效期状态判定：
- 正常：距效期 > 180天
- 近效期（黄色）：距效期 90~180天
- 临近效期（橙色）：距效期 30~90天
- 过期预警（红色）：距效期 < 30天
- 已过期：已过效期，禁止出库

定时任务：
- 每日02:00扫描效期，生成预警记录
- 预警消息推送：站内信 + 邮件 + 短信（可配置）
```

## 库存出库策略

```
先进先出（FIFO）：按批次入库时间顺序出库
近效期先出：按效期远近顺序出库（医疗耗材优先）
指定批次：支持手动指定出库批次
```
