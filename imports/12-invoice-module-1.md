# 发票管理模块 (spd-invoice)

## 模块定位

发票登记、发票审核、发票开具、发票签收

## 功能说明

| 功能 | 说明 |
|------|------|
| 发票登记 | 发票信息录入、关联结算单、价税信息录入 |
| 发票审核 | 发票合规性审核、发票信息校验、审核意见 |
| 发票开具 | 供应商开票、电子发票上传、发票文件管理 |
| 发票签收 | 医院签收确认、签收日期、签收意见 |
| 发票查询 | 按供应商/医院/日期/状态多维查询、发票统计 |

## 核心API

```java
// 发票分页查询
GET /api/invoice/page?pageNum=1&pageSize=10&hospitalId=xxx&settlementId=xxx&status=1

// 登记发票
POST /api/invoice
Body: {invoiceNo, invoiceCode, invoiceType, settlementId, hospitalId, invoiceDate, invoiceAmount, taxAmount, totalAmount, taxRate, fileUrl}

// 更新发票
PUT /api/invoice/{id}
Body: {invoiceNo, invoiceCode, invoiceType, invoiceDate, invoiceAmount, taxAmount, totalAmount, taxRate, fileUrl, remark}

// 删除发票
DELETE /api/invoice/{id}

// 发票审核
PUT /api/invoice/{id}/audit
Body: {auditStatus, auditRemark}

// 发票签收
PUT /api/invoice/{id}/sign
Body: {signRemark}

// 发票退回
PUT /api/invoice/{id}/return
Body: {returnReason}

// 发票作废
PUT /api/invoice/{id}/void
Body: {voidReason}

// 上传发票文件
POST /api/invoice/{id}/file
Body: multipart/form-data

// 获取发票文件
GET /api/invoice/{id}/file
```

## 发票状态流转

```
待审核 ──审核通过──→ 已审核 ──签收──→ 已签收
   │                      │
   └───审核驳回──→ 驳回  └──退回──→ 已退回
```

## 页面按钮 - API - 状态 - 异常码对照表

| 页面按钮 | 对应 API | 允许状态 | 成功后状态 | 主要异常码 |
|----------|----------|----------|------------|------------|
| 新增 | `POST /api/invoice` | 结算已完成、待开票 | 待审核 | `SETTLEMENT_NOT_COMPLETED`、`INVOICE_AMOUNT_MISMATCH` |
| 编辑 | `PUT /api/invoice/{id}` | 待审核、驳回、已退回 | 待审核 | `INVOICE_LOCKED`、`INVOICE_NO_DUPLICATED` |
| 删除 | `DELETE /api/invoice/{id}` | 待审核、驳回 | 已作废 | `INVOICE_AUDITED`、`INVOICE_NOT_FOUND` |
| 审核 | `PUT /api/invoice/{id}/audit` | 待审核 | 已审核或驳回 | `AUDIT_STATUS_INVALID`、`FILE_REQUIRED` |
| 签收 | `PUT /api/invoice/{id}/sign` | 已审核 | 已签收 | `SIGN_PERMISSION_DENIED` |
| 查看 | `GET /api/invoice/page` | 全部 | 原状态不变 | `INVOICE_NOT_FOUND` |
| 打印 | `GET /api/invoice/{id}/file` | 已审核、已签收 | 原状态不变 | `FILE_NOT_FOUND` |
| 导出 | `GET /api/invoice/page` | 全部 | 原状态不变 | `EXPORT_TOO_MANY_ROWS` |

## 状态转移条件与失败回滚

| 转移 | 可转移条件 | 禁止转移 | 失败回滚 |
|------|------------|----------|----------|
| 待开票 → 待审核 | 结算单已完成，发票金额与结算金额匹配，文件上传成功 | 结算单未完成、金额不一致、发票号码重复 | 删除临时文件引用，保持结算待开票 |
| 待审核 → 已审核 | 发票号码、代码、金额、税率、文件均校验通过 | 文件缺失、金额不匹配、税额计算错误 | 保持待审核，记录审核失败原因 |
| 待审核 → 驳回 | 审核意见填写驳回原因 | 驳回原因为空 | 保持待审核 |
| 已审核 → 已签收 | 医院确认收到发票，签收人有权限 | 发票文件不可访问、医院无权限 | 保持已审核 |
| 已审核 → 已退回 | 医院填写退回原因，发票未签收 | 已签收或已作废 | 保持已审核 |
| 待审核/驳回 → 已作废 | 作废原因完整，发票未被签收 | 已签收、已关联付款 | 保持原状态 |

### 发票编辑弹窗

#### 弹窗布局
```
┌─────────────────────────────────────────────────────────────────┐
│  编辑发票 - FP20240001                     [×]              │
├─────────────────────────────────────────────────────────────────┤
│  基本信息: 发票号码* 发票代码* 发票类型* 关联结算单* 医院*  │
│  价税信息: 发票日期* 发票金额* 税额* 价税合计* 税率*        │
│  发票文件: [点击上传] (支持PDF/JPG/PNG，≤10MB)              │
│  备注: [多行文本框]                                              │
│                              [取消]  [保存]  [提交审核]           │
└─────────────────────────────────────────────────────────────────┘
```

#### 表单字段说明

| 区域 | 字段 | 必填 | 说明 |
|------|------|------|------|
| 基本信息 | 发票号码 | 是 | 同一租户下不可重复 |
| 基本信息 | 发票代码 | 是 | 按税务发票规则填写 |
| 基本信息 | 发票类型 | 是 | 电子普通发票、电子专票、纸质普票、纸质专票 |
| 基本信息 | 关联结算单 | 是 | 只能选择已完成且待开票的结算单 |
| 基本信息 | 医院 | 是 | 根据关联结算单自动带出 |
| 价税信息 | 发票日期 | 是 | 不得早于结算完成日期 |
| 价税信息 | 发票金额、税额、价税合计、税率 | 是 | 价税合计需与结算可开票金额匹配 |
| 发票文件 | 文件 | 是 | 支持 PDF、JPG、PNG，单文件不超过 10MB |
| 备注 | 备注 | 否 | 记录开票或签收说明 |

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|----------|
| 取消 | 关闭弹窗，不保存修改 |
| 保存 | 保存发票草稿或待审核发票 |
| 提交审核 | 校验发票金额、文件和结算关系后提交审核 |

#### 提交校验规则

- 发票号码、发票代码、发票类型、关联结算单、价税信息和发票文件不能为空。
- 发票号码在当前租户下必须唯一。
- 发票金额 + 税额必须等于价税合计。
- 价税合计不得超过结算单剩余可开票金额。
- 发票审核通过后，除退回或作废流程外不得修改核心价税字段。
