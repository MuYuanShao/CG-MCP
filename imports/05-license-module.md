# 证照管理模块 (spd-license)

## 模块定位

供应商证照、商品证照管理、效期预警、合规校验

## 功能说明

| 功能 | 说明 |
|------|------|
| 供应商证照 | 营业执照、经营许可证、备案凭证、GSP证书等供应商资质管理 |
| 商品证照 | 医疗器械注册证、生产许可证、卫生许可证等商品资质管理 |
| 效期管理 | 证照到期前30/60/90天多级预警、预警消息推送 |
| 证照审核 | 证照上传→审核→生效/驳回完整流程、审核意见记录 |
| 证照关联 | 证照与供应商/商品多对多关联、证照有效期校验 |
| 合规校验 | 下单/发货前自动校验相关证照有效性、阻断违规操作 |

## 核心API

```java
// 证照分页查询
GET /api/license/page?pageNum=1&pageSize=10&licenseType=1&relatedType=1&keyword=xxx

// 上传证照
POST /api/license
Body: {licenseType, licenseNo, licenseName, issueDate, expireDate, issuingAuthority, fileUrl, relatedType, relatedId}

// 证照审核
PUT /api/license/{id}/audit
Body: {status, auditRemark}

// 获取证照预警列表
GET /api/license/alerts?alertLevel=1&isHandled=0

// 处理预警
PUT /api/license/alerts/{id}/handle
Body: {handleRemark}
```

## 证照状态流转

```
待审核 ──审核通过──→ 生效 ──效期临近──→ 预警 ──续期──→ 生效
   │                        │
   └───审核驳回──→ 驳回    └──过期──→ 过期
```

## 效期预警策略

```
- 90天预警（蓝色）：提醒即将到期，提前准备续期
- 60天预警（黄色）：需要立即处理
- 30天预警（红色）：紧急预警，业务操作受限
- 过期（黑色）：证照失效，禁止相关业务
```

#### 页面功能说明

**查询条件：**
| 查询项 | 查询方式 | 说明 |
|--------|---------|------|
| 证照分类 | 下拉选择 | 从证照分类表获取选项：合同、注册证、生产许可证、临采申请单、紧急采购单、议价表、经营许可证、营业执照、厂家授权书、法人代表人授权书、法定代表人身份证、被授权人身份证 |

| 合同编码 | 模糊查询 | 支持输入关键字模糊匹配合同编码 |
| 证照编码 | 模糊查询 | 支持输入关键字模糊匹配证照编码 |

**数据展示：**
- 页面默认展示当前登录账号的证照信息
- 每页默认展示25条数据
- 支持勾选多条数据（用于批量操作）
- 列表字段：证照编码、证照名称、证照分类、关联商品、医院名称、效期状态、状态

**效期状态标识：**
- 正常：绿色标识
- 近效期（黄色）：黄色标识，90~180天
- 临近效期（橙色）：橙色标识，30~90天
- 过期预警（红色）：红色标识，<30天
- 已过期：黑色标识，已过期

**页面按钮：**
| 按钮 | 功能说明 |
|------|---------|
| 新增 | 打开新增证照弹窗 |
| 编辑 | 选中一条数据，打开编辑证照弹窗 |
| 删除 | 选中一条或多条数据，删除证照 |

| 导出 | 导出当前查询结果为Excel文件 |

#### 证照文件上传规则

**文件格式要求：**
- 支持格式：PNG、PDF、JPG
- 文件大小：不超过 10 MB
- 支持多文件上传（可选）

**上传交互：**
- 点击"点击上传"打开文件选择器
- 选择文件后显示文件名
- 已上传文件显示"点击删除"按钮
- 文件上传前校验格式和大小
- 超出限制时提示错误信息

#### 弹窗操作按钮

| 按钮 | 功能说明 |
|------|---------|
| 取消 | 关闭弹窗，不保存数据 |
| 确认保存 | 校验表单数据，保存证照信息 |

**保存校验规则：**
- 必填字段不能为空
- 医院名称必须选择
- 证照分类必须选择
- 证照效期开始时间必须早于结束时间
- 证照文件如上传，需校验格式和大小

### 批量修改弹窗

#### 功能说明
支持批量修改以下字段：
- 证照效期（结束时间）
- 备注

#### 交互流程
1. 在列表页勾选多条证照
2. 点击"批量修改"按钮
3. 打开批量修改弹窗
4. 选择需要修改的字段（支持多选）
5. 输入新值
6. 点击"确认修改"
7. 系统更新所有选中证照的对应字段
