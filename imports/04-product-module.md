# 商品目录管理模块 (spd-product)

## 模块定位

商品主数据管理、供应商商品目录、医院商品映射、价格管理

## 功能说明

| 功能 | 说明 |
|------|------|
| 商品信息管理 | 商品CRUD（完整商品字段）、商品编码自动生成 |
| 商品分类 | 多级分类树、分类授权、分类排序 |
| 供应商商品目录 | 供应商维护的可供商品、供应价格、最小起订量、交货期、上下架管理 |
| 医院目录映射 | 供应商商品与医院目录的对照关系、医院商品编码/名称映射、医院采购价 |
| 价格管理 | 价格维护、价格生效/失效、历史价格追溯、价格变更审批 |
| 带量分类管理 | 带量分类表维护、带量商品分类 |
| 招采目录管理 | 招采子平台院内目录导入、招采子本地编码查询 |

## 商品编码生成规则

```
编码格式：{行业规则码}{流水号}

示例：
- 行业规则码：根据医疗行业分类规则生成（如：器械分类码+年份码）
- 流水号：4位数字，自增长（0000、0001、0002...）

完整编码示例：YLQX20240001
```

## 核心API

```java
// 商品分页查询
GET /api/product/page?pageNum=1&pageSize=10&categoryId=xxx&keyword=xxx

// 创建商品
POST /api/product
Body: {
  productName, genericName, specification, model, unitPrice, unit,
  registrationNo, medicalInsuranceCode, udi, categoryId,
  manufacturer, brand, isImported, isVolume, volumeCategoryId,
  zcLocalCode, mediumPackage, largePackage, hospitalContractCode
}

// 更新商品
PUT /api/product/{id}
Body: {同上}

// 获取商品详情
GET /api/product/{id}

// 获取分类树
GET /api/product/categories/tree

// 供应商商品分页查询
GET /api/product/supplier/page?pageNum=1&pageSize=10

// 添加供应商商品
POST /api/product/supplier
Body: {productId, supplyPrice, minOrderQty, leadTime, priceStartDate, priceEndDate}

// 商品上下架
PUT /api/product/supplier/{id}/on-shelf
PUT /api/product/supplier/{id}/off-shelf

// 添加医院商品映射
POST /api/product/hospital-mapping
Body: {hospitalId, supplierProductId, hospitalProductCode, hospitalProductName, hospitalPrice}

// 招采子本地编码查询（支持输入搜索）
GET /api/product/zc-local-code/search?keyword=xxx

// 带量分类列表
GET /api/product/volume-categories
```

## 业务流程

```
商品分类创建 → 商品主数据录入 → 供应商商品上架 → 医院商品映射 → 价格配置 → 商品可用
              ↑
         商品编码自动生成
```

## 商品创建流程

```
1. 选择商品分类
2. 填写商品基本信息（名称、通用名、规格、型号等）
3. 系统自动生成商品编码
4. 填写注册证号、医保编码、UDI等合规信息
5. 选择生产厂家、品牌、是否进口
6. 配置带量信息（带量分类、招采子本地编码）
7. 填写包装信息（中包装、大包装）
8. 关联院内合同编码
9. 保存商品信息
10. 供应商商品上架（可选）
```

### 批量修改弹窗

#### 功能说明
支持批量修改以下字段：
- 是否进口
- 是否带量
- 品牌
- 配送商

#### 交互流程
1. 在列表页勾选多条商品
2. 点击"批量修改"按钮
3. 打开批量修改弹窗
4. 选择需要修改的字段（支持多选）
5. 输入新值
6. 点击"确认修改"
7. 系统更新所有选中商品的对应字段
